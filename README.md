# DOCX Description Generator

This Python project reads the text and tables in a Word document and writes a
separate DOCX containing a concise, extractive summary. It does not require an
AI service or network access when run.

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Run

Place the source `.docx` beside `summarize_docx.py`, then run:

```powershell
python summarize_docx.py
```

The script automatically uses the only source DOCX in that folder and creates
`<source-name>_description.docx` beside it. If multiple source documents are
present, select one explicitly:

```powershell
python summarize_docx.py --input "path\to\source.docx"
```

You can also choose a different output path:

```powershell
python summarize_docx.py --input "path\to\source.docx" --output "path\to\summary.docx"
```

## Run automatically every day

On Windows, install a Task Scheduler task that runs this script every day at
10:00 AM local time:

```powershell
python summarize_docx.py --install-schedule
```

The task uses the Python interpreter currently running the command. The
computer must be on and the Windows account available when the task runs. To
remove the task, run:

```powershell
schtasks /Delete /TN "AutomationDocxDescriptionDaily" /F
```

The summary is generated by selecting representative sentences from the source
text. Text in document tables is included; embedded images are not described.

## CI/CD

GitHub Actions runs syntax and DOCX-generation checks on Python 3.10 and 3.14
for pull requests and pushes to `main`. Successful pushes to `main` also
produce a downloadable ZIP artifact containing the script, dependencies, and
this README. Sample DOCX files are not included in the package.

To publish a GitHub Release with the ZIP attached, push a version tag after the
checks pass:

```powershell
git tag v1.0.0
git push origin v1.0.0
```
